আমার প্রতিদিন — Saree Craftline Routine

এই ফোল্ডারে একটি ফ্রি মোবাইল-ফ্রেন্ডলি রুটিন অ্যাপ আছে।

ব্যবহার:
১) index.html ফাইলটি কম্পিউটার বা মোবাইলের ব্রাউজারে খুললে রুটিন দেখা যাবে।
২) কাজ শেষ হলে ডান পাশের বক্সে টিক দেবে। অগ্রগতি এই ডিভাইসের ব্রাউজারে সেভ থাকবে।
৩) নামাজের সময় বদলালে “নিজের যত্ন” ট্যাবে গিয়ে সময় পরিবর্তন করে “সময় সেভ করো” চাপবে।
৪) নতুন দিনে চেকলিস্ট নতুন হবে।

Android-এ হোম স্ক্রিনে অ্যাপ হিসেবে ইনস্টল:
PWA ইনস্টল করার জন্য ফাইলগুলো HTTPS ওয়েবসাইটে রাখতে হবে। শুধু ZIP খুলে index.html চালালে অ্যাপের রুটিন চলবে, তবে Install/Offline PWA সুবিধা নাও পাওয়া যেতে পারে।

বিনামূল্যে প্রকাশের একটি উপায়:
- GitHub-এ একটি নতুন Public repository তৈরি করো।
- ZIP-এর ভেতরের ফাইলগুলো (index.html, manifest.webmanifest, sw.js, icons ফোল্ডার) repository-র মূল জায়গায় Upload করো।
- Repository Settings > Pages > Deploy from a branch > main / root নির্বাচন করে Save করো।
- GitHub Pages-এর তৈরি HTTPS লিংক Android Chrome-এ খোলো।
- Chrome-এর তিন ডট মেনু > Add to Home screen / Install app চাপো।

দ্রষ্টব্য:
- কোনো লগইন, পেমেন্ট বা সার্ভার ডেটাবেস নেই।
- টিক দেওয়া কাজ ও সময় তোমার ডিভাইসের browser storage-এ থাকে। Browser data মুছে ফেললে এগুলো মুছে যেতে পারে।
- নামাজের সময় ঋতু ও এলাকার ভিত্তিতে বদলায়; অ্যাপের Settings-এ সময় আপডেট করবে।
- এটি ব্যক্তিগত রুটিন অ্যাপ, কোনো নামাজের সময় নির্ধারণকারী বা অ্যালার্ম অ্যাপ নয়।
